Configuración de la aplicación Bear Console

Los parámetros de la aplicación se dividen en dos secciones: General y Telemetría[cite: 10].

1. Parámetros Generales

  • Idioma de la aplicación: Idioma activo (por defecto, sigue automáticamente el idioma del sistema Android)[cite: 10].
  • Color del gráfico: Ajusta el color del trazo de las curvas de vuelo[cite: 10].
  • Unidades de la aplicación: Alterna entre el sistema métrico (metros, m/s) e imperial (pies, ft/s)[cite: 10].
  • Color de fondo del gráfico: Configura el color de fondo. ¡Asegúrese de que contraste con el color de la curva[cite: 10]!
  • Tamaño de fuente: Ajusta el tamaño del texto para una lectura óptima[cite: 10].
  • Velocidad en baudios: Configuración para conexión USB (debe coincidir exactamente con la velocidad del altímetro, normalmente 38400)[cite: 10].
  • Tipo de conexión: Permite seleccionar entre Bluetooth o USB (cable directo o radioenlaces de larga distancia)[cite: 10].
  • Biblioteca de gráficos: Permite elegir entre dos motores de renderizado. Advertencia: en dispositivos con Android 8 o superior, debe utilizar obligatoriamente la biblioteca MPAndroidChart para evitar cierres inesperados[cite: 10].
  • Múltiples Main / Drogue: Permite asignar más de una salida pirotécnica para el paracaídas principal o extractor (drogue)[cite: 10].
  • Soporte USB completo: Habilítelo únicamente si se conecta mediante un cable USB[cite: 10]. Manténgalo desactivado si utiliza módulos de radio de largo alcance (LoRa o 3DR) para evitar corromper la configuración de su altímetro[cite: 10].

2. Configuración de Telemetría

  • Eventos de voz: Selecciona qué eventos de vuelo se anunciarán por voz en tiempo real (despegue, apogeo, despliegue, etc.)[cite: 10].
  • Voz de telemetría: Permite seleccionar la voz del sintetizador de voz (TTS)[cite: 10].
  • Prueba de voz: Pulse el botón [Probar voz] para comprobar el volumen y la pronunciación[cite: 10].

Guardar cambios

Haga clic en [Guardar] para aplicar las modificaciones[cite: 10]. También puede salir sin guardar o restablecer los valores predeterminados de fábrica[cite: 10].
