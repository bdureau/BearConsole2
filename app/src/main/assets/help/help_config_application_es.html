Configuración de la aplicación Bear Console

Los parámetros de la aplicación se dividen en dos secciones: General y Telemetría.

1. Parámetros Generales

Idioma de la aplicación: Idioma activo (por defecto, sigue automáticamente el idioma del sistema Android).

Color del gráfico: Ajusta el color del trazo de las curvas de vuelo.

Unidades de la aplicación: Alterna entre el sistema métrico (metros, m/s) e imperial (pies, ft/s).

Color de fondo del gráfico: Configura el color de fondo. ¡Asegúrese de que contraste con el color de la curva!

Tamaño de fuente: Ajusta el tamaño del texto para una lectura óptima.

Velocidad en baudios: Configuración para conexión USB (debe coincidir exactamente con la velocidad del altímetro, normalmente 38400).

Tipo de conexión: Permite seleccionar entre Bluetooth o USB (cable directo o radioenlaces de larga distancia).

Biblioteca de gráficos: Permite elegir entre dos motores de renderizado. Advertencia: en dispositivos con Android 8 o superior, debe utilizar obligatoriamente la biblioteca MPAndroidChart para evitar cierres inesperados.

Múltiples Main / Drogue: Permite asignar más de una salida pirotécnica para el paracaídas principal o extractor (drogue).

⚠ ADVERTENCIA DE CONFIGURACIÓN USB
Soporte USB completo: Habilítelo únicamente si se conecta mediante un cable USB. Manténgalo desactivado si utiliza módulos de radio de largo alcance (LoRa o 3DR) para evitar corromper la configuración de su altímetro.

2. Configuración de Telemetría

Eventos de voz: Selecciona qué eventos de vuelo se anunciarán por voz en tiempo real (despegue, apogeo, despliegue, etc.).

Voz de telemetría: Permite seleccionar la voz del sintetizador de voz (TTS).

Prueba de voz: Pulse el botón [Probar voz] para comprobar el volumen y la pronunciación.

Guardar cambios

Haga clic en [Guardar] para aplicar las modificaciones. También puede salir sin guardar o restablecer los valores predeterminados de fábrica.
