Настройка приложения Bear Console

Настройки приложения разделены на две основные вкладки: Общие и Телеметрия.

1. Общие настройки

Язык приложения: Отображает текущий язык (по умолчанию соответствует языку системы Android).

Цвет графика: Настройка цвета линий графиков полета (высота, скорость, ускорение).

Единицы измерения: Переключение между метрической (метры, м/с) и имперской (футы, фут/с) системами.

Цвет фона графика: Выбор цвета фона. Убедитесь, что фон контрастирует с цветом линий графика!

Размер шрифта: Настройка размера текста для удобства чтения параметров.

Скорость (Baud rate): Скорость передачи данных по USB-кабелю (должна совпадать со скоростью высотомера, обычно 38400 бод).

Тип подключения: Выбор между Bluetooth (ближняя связь) и USB (прямое кабельное подключение или радиомодули дальней связи).

Графическая библиотека: Выбор библиотеки построения графиков. Внимание: на устройствах с Android 8.0 и выше обязательно используйте библиотеку MPAndroidChart во избежание сбоев в работе приложения.

Несколько каналов Main / Drogue: Позволяет назначить более одного пиропатрона для основного или тормозного парашюта.

⚠ ВНИМАНИЕ: НАСТРОЙКА USB
Полная поддержка USB: Включайте только при прямом проводном подключении через USB-кабель. Не включайте при использовании радиомодулей дальней связи (LoRa / 3DR), чтобы избежать повреждения прошивки и настроек высотомера.

2. Настройка телеметрии

Голосовые оповещения: Выбор событий полета, которые озвучиваются в реальном времени (старт, апогей, раскрытие парашюта и т. д.).

Голос телеметрии: Выбор голоса системы синтеза речи (TTS).

Проверка звука: Нажмите кнопку [Проверить голос] для проверки громкости и разборчивости речи.

Сохранение настроек

Нажмите [Сохранить], чтобы применить внесенные изменения. Вы также можете выйти без сохранения или сбросить все параметры к заводским значениям.
