Flight Screen Help File

The Flight section is organized into two dedicated screens:

Curve View: Plots interactive flight curves (altitude, acceleration, velocity). On this screen, you can choose which specific curves you want to display or hide.

Flight Info: Displays a complete summary of the flight telemetry (apogee, maximum velocity, burn time, descent rates). You can also export the recorded raw flight data to a CSV file.

Export Tip: The generated CSV file can be analyzed in external software or spreadsheet tools for in-depth flight and performance review.
