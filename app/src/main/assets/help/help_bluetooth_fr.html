Choix du module Bluetooth

Vous serez amené à choisir un type de module Bluetooth si aucun n'a été sélectionné ou si vous voulez vous connecter à un altimètre différent.

Procédure d'appairage et de sélection

  1. Appairage système : Vous devez d'abord appairer tous les modules Bluetooth de vos altimètres dans les paramètres Bluetooth de votre appareil Android (le code PIN par défaut est généralement 1234 ou 0000).
  2. Sélection : Dans la liste des modules configurés, sélectionnez celui utilisé par votre altimètre actif.
  3. Connexion : Quittez l'écran et connectez-vous à nouveau. Si vous avez choisi le mauvais module ou si l'altimètre est hors tension, la connexion ne s'établira pas.
⚠ CONSEIL IMPORTANT
Faites attention à bien différencier et renommer vos modules sur votre téléphone de manière à toujours vous connecter au bon altimètre.
