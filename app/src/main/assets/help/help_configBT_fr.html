Configuration du module Bluetooth

Pour connecter votre altimètre à votre téléphone ou tablette Android via Bluetooth, le module doit impérativement fonctionner à la même vitesse de communication (vitesse en bauds) que la carte altimètre.

Cet écran vous permet de programmer facilement des modules standards tels que les HC-05, HC-06, JDY-30, JDY-31, SPP et AT-09.

Matériel requis

  • Un câble adaptateur USB-Série TTL.
  • Un adaptateur USB OTG (USB-C ou Micro-USB selon votre appareil Android).
  • Un adaptateur JST et des cordons de liaison JST.

Harmonisation de la vitesse (Baud Rate)

La plupart de ces modules sont livrés préconfigurés à 9600 bauds. Or, votre carte altimètre est programmée par défaut pour communiquer à 38400 bauds. Il est donc indispensable d'ajuster ce paramètre.

⚠ ATTENTION
Ne débranchez jamais le module ou le câble pendant la lecture ou l'écriture des paramètres afin de ne pas corrompre sa mémoire.

Lire la configuration du module

  1. Raccordement matériel : Raccordez le module Bluetooth à votre appareil Android à l'aide du câble TTL et de l'adaptateur USB OTG.
  2. Sélection du modèle : Sélectionnez le modèle de votre module dans le menu déroulant. Si vous ne le connaissez pas, choisissez HC-05, HC-06 ou Unknown. Si aucun profil ne répond, contactez le support en joignant une photo et la référence du composant.
  3. Lecture des paramètres : Appuyez sur [Charger cfg]. L'application essaie d'abord de se connecter à la vitesse par défaut de 38400 bauds. En cas d'échec, elle teste automatiquement plusieurs vitesses jusqu'à établir la communication.
  4. Affichage : Une fois connecté, les paramètres actuels (Nom, Débit, Code PIN) s'affichent à l'écran.

Sauvegarder la nouvelle configuration

  1. Modification des champs : Modifiez les champs souhaités (Nom du module, code PIN, Vitesse). Assurez-vous de choisir la vitesse attendue par votre carte altimètre (en général 38400 bauds).
  2. Écriture : Appuyez sur [Sauver cfg]. Les commandes AT sont alors transmises et enregistrées dans le module. En cas d'erreur de confirmation, la procédure est automatiquement interrompue.
Remarque : Répétez ces mêmes étapes individuellement pour chaque module Bluetooth que vous devez préparer.
