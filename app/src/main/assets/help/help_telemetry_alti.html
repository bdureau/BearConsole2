Telemetry

This provides several screens to display telemetry when using a long range telemetry module.

Voice Annunciations: The telemetry system can verbally announce flight events. You can configure the synthetic voice and select the desired trigger events in the application settings.

Available Telemetry Screens

  • Altitude & Event Graph: A real-time plot displaying current altitude and flight events as they occur.
  • Altimeter Health & Diagnostics: Real-time parameters including altimeter model, firmware version, deployment channel continuity, battery voltage, and instantaneous altitude.
  • GPS Coordinates (AltiGPS): For GPS-equipped units, this screen presents relative navigation data, heading, and distance between your mobile device and the rocket.
  • Live Map (AltiGPS): An interactive map displaying the real-time positions of both your phone and the rocket to visualize flight trajectory and direction.
Recovery Tracking: To recover your rocket after landing, use the dedicated tracking screen which automatically memorizes and saves the last known coordinates sent by the transmitter.
