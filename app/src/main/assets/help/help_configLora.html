eByte LoRa E220 Module Configuration

In order to do long range telemetry you will need to replace your Bluetooth module with a long range telemetry module such as the LoRa E220.

Successfully Tested Modules

  • E220-400T30D
  • E220-400T30S
  • E220-900T30D
  • E220-900T30S
  • E220-400T22D
  • E220-900T22S

Power Note: Note that your Android device battery must be strong enough to power the LoRa module. Consider using an external battery or a powered USB hub if you have a powerful module (such as 30dBm / 1W models).

Required Hardware

  • A USB-to-TTL serial adapter cable.
  • A USB adapter (USB-C or Micro-USB depending on your Android device).
  • A JST adapter and matching JST connector cables.
⚠ CRITICAL: HARDWARE JUMPERS (M0 / M1)
In order to enter configuration mode, you will need to install both jumpers (M0 and M1 set to HIGH). Before you use it in flight, make sure you remove both jumpers to exit configuration mode and return to normal transmission.

Baud Rate Alignment

You will need to configure the module so that it works with your altimeter board. Note that these modules usually come preset to work at 57600 baud. However, your altimeter board by default will work at 38400 baud, so you need to make sure that you are connecting at the correct operating speed.

⚠ CAUTION
Make sure that you do not unplug or disconnect the module while performing configuration steps.

Configuration Steps

  1. Hardware Setup: Place both jumpers on the module. Connect the module to your Android device using the USB-TTL cable and OTG adapter.
  2. Retrieving Configuration: Tap [Retrieve cfg]. This will attempt to connect to the module using 9600 baud. It will then load the module configuration so that you can edit it.
  3. Saving Configuration: Change the parameters you want to modify. Ensure you select a baud rate compatible with your board (by default 38400). Make sure that the channels and air rates are identical on both the transmitter and receiver. If you set an encryption key, verify it matches on both. Tap [Save cfg] to write the configuration. If an error occurs, the save process will abort.
  4. Return to Normal Mode: Unplug the module and remove both jumpers before installation into the rocket or ground station.
Paired Setup: LoRa modules come in pairs, so you will need to repeat the same configuration procedure for both the transmitter and receiver.
Note: LoRa telemetry modules currently do not work with ESP32 boards.
