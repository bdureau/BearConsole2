Guida per la schermata di volo

La sezione relativa al volo è suddivisa in 2 schermate dedicate:

Vista delle curve: Traccia tutte le curve di volo (quota, accelerazione, velocità). In questa schermata è possibile scegliere quali curve visualizzare o nascondere.

Informazioni sul volo: Mostra un riepilogo dettagliato del volo (apogeo, velocità massima, tempo di spinta, velocità di discesa). Da qui è inoltre possibile esportare tutti i dati registrati in formato CSV.

Suggerimento per l'esportazione: Il file CSV esportato può essere aperto con software di calcolo o programmi esterni per un'analisi approfondita delle prestazioni.
