Bear Altimeter Console Help File

This is a quick help file to use your Android Bear Altimeter console. The Android console is a very convenient way to reconfigure your altimeter when you are on the field.

Note: Help is context-sensitive on each screen; it displays specific help relevant to the screen currently in use.

Initial Setup & Bluetooth Pairing

  1. Firmware Verification: Make sure that your altimeter is compatible (i.e., the correct firmware has been loaded).
  2. Module Connection: Make sure that the Bluetooth module is properly connected to the altimeter.
  3. System Pairing: Open your Android device settings, navigate to Bluetooth configuration, and scan for the HC-05, HC-06, or HC-07 Bluetooth module. Once found, enter the pairing PIN code, which is 1234 by default.
⚠ CAUTION
You should clearly rename each paired Bluetooth device on your phone to make sure you are configuring the correct altimeter.
  1. Power On: Turn on the altimeter and wait until it beeps for continuity confirmation.
  2. Connection: Start the BearConsole application on your Android device, tap on paired devices, and select your module (HC-05 or HC-06). The console will now attempt to connect to the altimeter.

Once connected, you can use the console to configure your altimeter or download recorded flight data. If it fails to connect, verify that the altimeter is powered on and that the correct Bluetooth adapter was selected.

Using the Altimeter Console

Altimeter Main Screen

The main screen features multiple action cards:

[Altimeter Settings]

Reads the current altimeter settings and allows you to modify them.

[Flights]

Reads all recorded flights from EEPROM/Flash memory and plots them as interactive curves.

[Telemetry]

Accesses real-time telemetry streaming from the flight computer.

[Continuity ON/OFF]

Toggles the continuity audio beeper on and off.

[Reset Settings]

Restores the altimeter configuration to factory defaults. Also allows clearing all stored flights or only the last flight record.

[Status]

Opens the diagnostic status screen, displaying deployment channel continuity, memory consumption, sensor health, and current altitude.

[Flash Firmware]

Allows flashing new firmware versions directly via USB OTG cable (available for ATmega328, STM32, and ESP32 platforms).

[Connect / Disconnect]

Establishes or terminates the serial connection with the altimeter.

Altimeter Main Screen Menu

From the options menu, you can access this help guide, the "About" screen containing version details, application theme preferences, and configuration panels for 3DR radio, Bluetooth, and LoRa telemetry transceivers.
