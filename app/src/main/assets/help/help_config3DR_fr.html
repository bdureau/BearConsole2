Configuration du module 3DR

De manière à pouvoir faire de la télémétrie longue distance, vous devez remplacer votre module Bluetooth par un module de télémétrie 3DR.

Alimentation électrique : À noter que la batterie de votre appareil Android doit être suffisamment puissante pour alimenter le module 3DR. Envisagez l'utilisation d'une batterie externe si vous avez un module puissant.

Matériel requis

  • Un câble adaptateur USB vers série TTL.
  • Un adaptateur USB (USB-C ou Micro-USB suivant votre appareil Android).
  • Un adaptateur JST et des câbles JST.

Compatibilité de vitesse (Baud Rate)

Vous devez configurer votre module de manière à ce qu'il puisse fonctionner avec votre altimètre. À noter que ces modules sont en général préconfigurés à 57600 bauds. Cependant, votre altimètre par défaut sera configuré à 38400 bauds : vous devez donc vous assurer de vous connecter à la bonne vitesse.

⚠ ATTENTION
Assurez-vous de ne pas débrancher le module lorsque vous effectuez les opérations suivantes.

Procédure de configuration

  1. Charger la configuration : Branchez le module sur votre appareil Android en utilisant un câble OTG ou un adaptateur USB. Ensuite, cliquez sur [Charger cfg] : cela effectuera des tentatives de connexion à différentes vitesses jusqu'à établir la liaison, puis la configuration sera affichée.
  2. Sauvegarder la configuration : Modifiez les paramètres souhaités. Assurez-vous d'avoir choisi la vitesse qui fonctionnera avec votre carte (38400 bauds) et cliquez sur [Sauver cfg]. En cas d'erreur lors de la sauvegarde, celle-ci sera annulée.
Modules par paire : À noter que les modules 3DR sont vendus par paire, il sera donc nécessaire de répéter la même opération pour l'émetteur et le récepteur.
