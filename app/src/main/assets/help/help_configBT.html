Bluetooth Module Configuration

To connect your altimeter to your Android smartphone or tablet via Bluetooth, the module must operate at the same communication baud rate as the altimeter board.

This utility enables you to configure compatible modules such as HC-05, HC-06, JDY-30, JDY-31, SPP, and AT-09.

Required Hardware

  • A USB-to-TTL serial adapter cable.
  • An OTG USB adapter (USB-C or Micro-USB depending on your Android device).
  • A JST adapter and matching JST connector cables.

Baud Rate Alignment

Most commercial Bluetooth modules arrive preconfigured at 9600 baud. However, the altimeter flight computer communicates by default at 38400 baud. You must configure your module to match this speed.

⚠ CAUTION
Do not disconnect the module or cable during the read or write sequence to prevent firmware or register corruption.

Retrieving the Module Configuration

  1. Hardware Connection: Connect the Bluetooth module to your Android device using the TTL cable and USB-OTG adapter.
  2. Select Module Type: Select your module type from the dropdown menu. If uncertain, select HC-05, HC-06, or Unknown. If no profile works, contact support with clear pictures and references of your module.
  3. Read Parameters: Tap [Retrieve cfg]. The application will first attempt to communicate at 38400 baud. If unacknowledged, it will scan through alternate standard baud rates until synchronization is achieved.
  4. Review Settings: Once connected, the current settings (Name, Baud Rate, PIN) will load automatically.

Saving the Configuration

  1. Modify Parameters: Adjust the parameters as required (Module Name, PIN, and Baud Rate). Ensure the selected baud rate matches your altimeter board (typically 38400 baud).
  2. Write Parameters: Tap [Save cfg]. The configuration commands will be written to the module. If a command error is detected, the process will halt safely.
Note: Repeat this configuration procedure individually for any additional Bluetooth modules you intend to use.
