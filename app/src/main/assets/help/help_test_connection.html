Test Connection Help File

This screen will allow you to test connection reliability, in particular with 3DR telemetry modules. It displays the number of data packets that get dropped due to poor signal quality or bad connection.

Usage Recommendation: Run a connection link check on the launch pad before flight to ensure your telemetry radio operates with an adequate link margin.

Monitored Connection Metrics

Packets Sent / Received: Total count of test data frames transmitted across the active telemetry link.

Dropped Packets: The count of lost or unacknowledged data frames resulting from RF interference, antenna misalignment, or excessive range.

Packet Loss Rate (%): Percentage of dropped packets relative to total transmissions. A rate below 2% ensures reliable real-time telemetry.

⚠ PRE-FLIGHT WARNING
Avoid launching if significant packet loss occurs on the pad. High loss indicates RF interference, misaligned antennas, or insufficient power to the transceiver.
