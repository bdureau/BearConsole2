Bear Console Application Settings

The application settings are organized into two dedicated tabs: General and Telemetry[cite: 9].

1. General Settings

  • Application Language: Displays the selected language (by default, it automatically follows your Android system language)[cite: 9].
  • Graph Color: Configures the plot line color for flight curves (altitude, acceleration, velocity)[cite: 9].
  • Application Units: Toggles between Metric (meters, m/s) and Imperial (feet, ft/s) units[cite: 9].
  • Graph Background Color: Sets the background color of the chart view. Ensure it contrasts sufficiently with the plot line color[cite: 9]!
  • Font Size: Adjusts text size across graphs and console displays[cite: 9].
  • Baud Rate: Configures the communication speed for direct USB OTG cable connections (must match the altimeter's serial baud rate, typically 38400)[cite: 9].
  • Connection Type: Selects between Bluetooth (short-range) or USB (direct cable or long-range LoRa/3DR radio transceivers)[cite: 9].
  • Graphics Library: Allows switching between rendering backends. Note: Devices running Android 8.0 and above must use the MPAndroidChart library to prevent application crashes[cite: 9].
  • Multiple Main / Drogue: Enables defining more than one pyrotechnic output as a main chute or drogue chute deployment event[cite: 9].
  • Full USB Support: Enable only when wired directly to the altimeter board via a USB-TTL cable[cite: 9]. Keep disabled when using wireless long-range telemetry modules (LoRa / 3DR) to prevent EEPROM configuration corruption[cite: 9].

2. Telemetry Settings

  • Audio Events: Selects which flight events are announced verbally in real time (e.g., Liftoff, Apogee, Main deployment, Altitude)[cite: 9].
  • Speech Synthesis Voice: Selects the Text-to-Speech (TTS) voice used for callouts[cite: 9].
  • Voice Test: Tap the [Test Voice] button to verify audio volume and synthesized voice clarity[cite: 9].

Saving Changes

Tap [Save] to apply and store your new parameters[cite: 9]. You may also exit without saving changes or reset to factory defaults via the corresponding menu options[cite: 9].
