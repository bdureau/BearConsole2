Bear Console Application Settings

The application settings are organized into two dedicated tabs: General and Telemetry.

1. General Settings

Application Language: Displays the selected language (by default, it automatically follows your Android system language).

Graph Color: Configures the plot line color for flight curves (altitude, acceleration, velocity).

Application Units: Toggles between Metric (meters, m/s) and Imperial (feet, ft/s) units.

Graph Background Color: Sets the background color of the chart view. Ensure it contrasts sufficiently with the plot line color!

Font Size: Adjusts text size across graphs and console displays.

Baud Rate: Configures the communication speed for direct USB OTG cable connections (must match the altimeter's serial baud rate, typically 38400).

Connection Type: Selects between Bluetooth (short-range) or USB (direct cable or long-range LoRa/3DR radio transceivers).

Graphics Library: Allows switching between rendering backends. Note: Devices running Android 8.0 and above must use the MPAndroidChart library to prevent application crashes.

Multiple Main / Drogue: Enables defining more than one pyrotechnic output as a main chute or drogue chute deployment event.

⚠ USB CONFIGURATION WARNING
Full USB Support: Enable only when wired directly to the altimeter board via a USB-TTL cable. Keep disabled when using wireless long-range telemetry modules (LoRa / 3DR) to prevent EEPROM configuration corruption.

2. Telemetry Settings

Audio Events: Selects which flight events are announced verbally in real time (e.g., Liftoff, Apogee, Main deployment, Altitude).

Speech Synthesis Voice: Selects the Text-to-Speech (TTS) voice used for callouts.

Voice Test: Tap the [Test Voice] button to verify audio volume and synthesized voice clarity.

Saving Changes

Tap [Save] to apply and store your new parameters. You may also exit without saving changes or reset to factory defaults via the corresponding menu options.
