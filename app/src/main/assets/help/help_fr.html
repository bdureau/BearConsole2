Fichier d'aide de la console d'altimètre Bear

Voici un guide d'aide rapide pour utiliser votre console d'altimètre Bear sous Android. La console Android constitue un moyen très pratique pour reconfigurer votre altimètre directement sur le terrain.

Note : L'aide est contextuelle sur chaque écran ; elle affiche l'aide spécifique correspondant à l'écran en cours d'utilisation.

Configuration initiale et appairage Bluetooth

  1. Vérification du firmware : Assurez-vous que votre altimètre est compatible (c'est-à-dire que le bon firmware a été chargé).
  2. Connexion du module : Vérifiez que le module Bluetooth est correctement raccordé à l'altimètre.
  3. Appairage système : Ouvrez les paramètres de votre appareil Android, accédez à la configuration Bluetooth et lancez la recherche du module Bluetooth HC-05, HC-06 ou HC-07. Une fois détecté, saisissez le code PIN d'association, qui est 1234 par défaut.
⚠ ATTENTION
Il est vivement conseillé de renommer clairement chaque périphérique Bluetooth appairé sur votre téléphone afin d'être certain de configurer le bon altimètre.
  1. Mise sous tension : Allumez l'altimètre et attendez qu'il émette les bips de confirmation de continuité.
  2. Connexion : Lancez l'application BearConsole sur votre appareil Android, appuyez sur les appareils appairés et sélectionnez votre module (HC-05 ou HC-06). La console tente alors d'établir la liaison avec l'altimètre.

Une fois connecté, vous pouvez utiliser la console pour configurer votre altimètre ou télécharger les données des vols enregistrés. Si la connexion échoue, vérifiez que l'altimètre est bien alimenté et que vous avez sélectionné le bon adaptateur Bluetooth.

Utilisation de la console de l'altimètre

Écran principal de l'altimètre

L'écran principal propose plusieurs cartes d'action :

[Paramètres de l'altimètre]

Lit les paramètres actuels de l'altimètre et vous permet de les modifier.

[Vols]

Lit l'ensemble des vols enregistrés dans la mémoire EEPROM/Flash et affiche leurs courbes de manière interactive.

[Télémétrie]

Accède au flux de télémétrie en temps réel émis par l'ordinateur de vol.

[Continuité ON/OFF]

Active ou désactive le signal sonore (buzzer) de continuité.

[Réinitialiser les paramètres]

Restaure la configuration de l'altimètre aux valeurs d'usine. Permet également d'effacer tous les vols enregistrés ou uniquement le dernier enregistrement.

[État]

Ouvre l'écran de diagnostic : affiche la continuité des canaux de déploiement, l'utilisation de la mémoire, l'état des capteurs et l'altitude actuelle.

[Flasher le firmware]

Permet de flasher de nouvelles versions de firmware directement via un câble USB OTG (disponible pour les plateformes ATmega328, STM32 et ESP32).

[Connexion / Déconnexion]

Établit ou interrompt la liaison série avec l'altimètre.

Menu de l'écran principal

Depuis le menu d'options, vous pouvez consulter ce fichier d'aide, ouvrir l'écran « À propos » contenant les informations de version, modifier les préférences d'affichage de l'application et accéder aux panneaux de configuration des modules de télémétrie radio 3DR, Bluetooth et LoRa.

Altimètres pris en charge

• AltiDuo (version complète avec ATmega328)

Il s'agit de l'AltiDuo original (mon tout premier altimètre) doté d'un firmware spécifique permettant une configuration intégrale depuis cette application. Il utilise un module Bluetooth branché sur son port série.

• AltiMulti V1

Altimètre à 3 sorties pyrotechniques qui enregistre le vol dans une EEPROM. Il utilise un module Bluetooth connecté sur le port série.

• AltiMulti V2

Version améliorée de l'AltiMulti. Elle utilise également un module Bluetooth connecté sur le port série.

• AltiServo

Permet de piloter des servomoteurs à la place des sorties pyrotechniques. Utilise un module Bluetooth sur le port série. Les servos ainsi que l'altimètre se configurent directement via cette application.

• AltiMulti STM32

Version 3 de l'AltiMulti architecturée autour d'un microcontrôleur STM32. Il offre 4 sorties pyrotechniques, enregistre les vols et dispose d'un port série additionnel pour raccorder des périphériques complémentaires.

• AltiGPS

Utilise la carte AltiMultiV3 avec un firmware adapté pour piloter un module GPS branché sur le port série.

• AltiMulti ESP32

4e version de l'AltiMulti basée sur une puce ESP32. Elle intègre 3 sorties pyrotechniques et l'enregistrement de vol. Aucun module Bluetooth externe n'est requis car il est nativement intégré sur le composant.

• AltiMulti ESP32 accel

Identique à l'AltiMulti ESP32, mais équipé de 2 accéléromètres sur la carte (ADXL345 et ADXL375).

• AltiMulti ESP32 accel 345

Identique à l'AltiMulti ESP32, mais avec un accéléromètre ADXL345 implanté sur la carte.

• AltiMulti ESP32 accel 375

Identique à l'AltiMulti ESP32, mais avec un accéléromètre ADXL375 implanté sur la carte.

• TTGO BearAltimeter

Conçu autour de la carte LilyGO avec l'ajout d'une carte fille (shield) équipée d'un capteur barométrique, d'un accéléromètre et d'une EEPROM pour sauvegarder les données de vol.

• TTGO T QT mini BearAltimeter

La carte d'altimètre la plus compacte ; elle embarque également une carte fille dédiée au capteur barométrique.

• TS-ESP32-S3 BearAltimeter

Cette petite carte intègre l'ensemble des fonctionnalités d'origine. Elle possède un capteur de pression et un accéléromètre intégrés. Les données de vol sont conservées dans la mémoire interne de la carte. Il suffit simplement de flasher le firmware correspondant depuis la liste.
