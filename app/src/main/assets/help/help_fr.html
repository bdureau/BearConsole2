Fichier d'aide de la Console Bear Altimeter

Ceci est un guide d'aide rapide pour utiliser votre console d'altimètre Bear sur Android. La console Android est un moyen très pratique de reconfigurer votre altimètre directement sur le terrain de lancement.

Remarque : L'aide est contextuelle : elle affiche les informations relatives à l'écran en cours d'utilisation.

Configuration initiale et appairage Bluetooth

  1. Vérification du firmware : Assurez-vous que votre altimètre est compatible (c'est-à-dire que le bon firmware a été préalablement flashé).
  2. Connexion du module : Assurez-vous que le module Bluetooth est correctement raccordé à l'altimètre.
  3. Appairage système : Ouvrez les paramètres de votre appareil Android, rendez-vous dans la configuration Bluetooth et lancez la recherche des modules HC-05, HC-06 ou HC-07. Une fois détecté, saisissez le code d'association qui est 1234 par défaut.
⚠ ATTENTION
Il est fortement recommandé de nommer clairement chaque périphérique Bluetooth appairé sur votre téléphone afin d'être certain de configurer le bon altimètre.
  1. Mise sous tension : Allumez l'altimètre et attendez qu'il émette les bips de confirmation de continuité.
  2. Connexion : Démarrez l'application sur votre appareil Android, appuyez sur « Afficher les appareils appairés », puis sélectionnez votre module HC-05 ou HC-06. L'application tente alors de se connecter à l'altimètre.

Si la mention « Connecté » apparaît, la liaison est établie et vous pouvez utiliser la Console pour configurer votre altimètre ou télécharger les vols. En cas d'échec, vérifiez que l'altimètre est bien allumé et que le bon adaptateur Bluetooth a été sélectionné.

Utilisation de la console altimètre

Écran principal de l'altimètre

Sur l'écran principal, plusieurs boutons d'action sont disponibles :

[Configuration Altimètre]

Lit la configuration actuelle de l'altimètre et vous permet de la modifier.

[Chargement Vols]

Lit l'ensemble des vols enregistrés en mémoire et trace les courbes graphiques associées.

[Télémétrie]

Affiche le flux de télémétrie en temps réel de l'ordinateur de vol.

[Continuité Marche/Arrêt]

Active ou désactive le signal sonore du bipeur de continuité.

[Réinit Config]

Permet de restaurer les paramètres d'usine de l'altimètre. Donne également la possibilité d'effacer tous les vols enregistrés ou seulement le dernier.

[État]

Accède à l'écran de diagnostic : affiche la continuité des canaux de déploiement, l'utilisation mémoire, la tension batterie et l'altitude courante.

[Flash Firmware]

Permet de mettre à jour le firmware à l'aide d'un câble USB OTG (disponible pour les cartes à base d'ATmega328, STM32 et ESP32).

[Connexion / Déconnexion]

Établit ou interrompt la connexion avec l'altimètre.

Menu de l'écran principal

Depuis le menu d'options, vous pouvez ouvrir ce guide d'aide, l'écran « À propos » précisant la version logicielle, personnaliser l'apparence visuelle de l'application et configurer les modules de télémétrie 3DR radio, Bluetooth ou LoRa eByte.

Altimètres compatibles

• AltiMulti V1

• AltiMulti V2

• AltiServo

• AltiGPS

• AltiMulti STM32

• AltiMulti ESP32

• AltiMulti ESP32 accel

• AltiMulti ESP32 accel 345

• AltiMulti ESP32 accel 375

• TTGO BearAltimeter

• TTGO T QT mini BearAltimeter
