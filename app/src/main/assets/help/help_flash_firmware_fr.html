Flashage du Firmware

Vous devez en premier lieu choisir le firmware à flasher. Le firmware dépend du modèle spécifique d'altimètre que vous souhaitez mettre à jour.

Décidez ensuite si vous souhaitez flasher directement le firmware opérationnel ou utiliser un firmware de récupération au préalable.

Firmware de récupération : Utilisez un firmware de récupération si la configuration de l'altimètre est corrompue et que celui-ci ne parvient plus à se connecter. Après avoir injecté un firmware de récupération, vous devrez flasher à nouveau le firmware opérationnel.
⚠ ATTENTION
Flasher un firmware inadapté rendra l'altimètre totalement inopérant ou provoquera un comportement imprévisible.

Matériel requis

  • Un câble convertisseur USB vers série TTL pour le raccorder à votre téléphone ou tablette.
  • Un adaptateur USB OTG (USB-C ou Micro-USB selon votre appareil Android).
  • Des câbles avec connecteurs JST.

Altimètres pris en charge

Observez attentivement les photos ci-dessous pour identifier précisément votre matériel :

• AltiDuo (Grand modèle)

• AltiServo

• AltiMulti

• AltiMultiV2

• AltiMultiSTM32 ou AltiGPS

• AltiMultiESP32

• AltiMulti ESP32 accel

• AltiMulti ESP32 accel 345

• AltiMulti ESP32 accel 375

• TTGO BearAltimeter

Instructions par famille de composants

Vous pouvez également lancer une détection automatique du firmware.

1. Altimètres à base d'ATmega328 (ex. : AltiDuo, AltiServo, AltiMulti, AltiMultiV2)

  • Raccordez le câble USB TTL à l'altimètre.
  • Sélectionnez le firmware approprié ou lancez la détection automatique.
  • Appuyez puis relâchez le bouton reset de l'altimètre, puis appuyez sur le bouton [Flash Firmware].

2. Altimètres à base de STM32 (ex. : AltiMultiSTM32, AltiGPS)

  • Raccordez le câble USB TTL.
  • Sélectionnez le firmware approprié ou lancez la détection automatique.
  • Basculez le cavalier BOOT0 vers la droite (position programmation) :

  • Appuyez sur le bouton reset de la carte.
  • Appuyez sur le bouton [Flash Firmware].
  • Le firmware se charge. Une fois le transfert terminé, remettez le cavalier BOOT0 vers la gauche (position normale) :

  • Appuyez sur le bouton reset pour redémarrer l'altimètre en mode normal.

3. Altimètres à base d'ESP32 (ex. : AltiMultiESP32, AltiMultiESP32Accel)

  • Raccordez le câble.
  • Sélectionnez le firmware approprié ou lancez la détection automatique.
  • Sur la carte, maintenez enfoncé le bouton BOOT.
  • Appuyez brièvement sur le bouton RESET et relâchez-le tout en maintenant le bouton BOOT enfoncé.
  • Relâchez ensuite le bouton BOOT :

  • Appuyez sur le bouton [Flash Firmware].
  • Le firmware doit commencer à se charger (recommencez en cas d'échec). Une fois le chargement terminé, appuyez sur le bouton reset.

4. TTGO BearAltimeter

  • Branchez directement le câble USB-C.
  • Sélectionnez le firmware correspondant à l'altimètre TTGO.
  • Appuyez sur le bouton [Flash Firmware]. Lorsque l'opération est terminée, appuyez sur le bouton reset.

5. TTGO Mini, Simple Altimeter et carte TS-ESP32-S3

  • Branchez le câble USB-C.
  • Maintenez enfoncé le bouton BOOT sur la carte.
  • Appuyez et relâchez le bouton RESET tout en maintenant le bouton BOOT enfoncé.
  • Relâchez le bouton BOOT et sélectionnez le modèle d'altimètre correspondant.
  • Appuyez sur le bouton [Flash Firmware]. Une fois terminé, appuyez sur le bouton reset.
⚠ REMARQUE IMPORTANTE
Ne débranchez jamais le câble durant l'opération de flashage. Cela corromprait le microprogramme et vous contraindrait à recommencer l'opération depuis le début.
