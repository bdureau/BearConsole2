Configure Altimeter

The altimeter configuration can span up to 4 different screens depending on the altimeter model connected. When opening these screens, the app connects to the altimeter and retrieves the configuration stored in onboard memory.

Connection Status: Ensure the altimeter is powered on and connected via Bluetooth or USB before updating parameters.

Altimeter Outputs

Each output channel can be configured and assigned a specific event-driven function:

  • Liftoff: Fires immediately at liftoff.
  • Timer: Fires X milliseconds after liftoff.
  • Altitude: Fires at the specified altitude threshold.
  • Apogee: Fires at detected apogee (peak altitude).
  • Main: Fires X meters before landing for main parachute recovery.
  • Landing: Fires upon ground touchdown.

Note: Each event can also be configured with an additional delay in milliseconds.

Altimeter Settings (Page 1)

Baud Rate: Sets communication port speed (reboot required).

Apogee Measures: Number of consecutive descending samples needed to confirm apogee.

Altimeter Resolution: Sensor sampling resolution.

⚠ CAUTION
Changing resolution can reduce the total number of flight measures. Do not lower it if the unit is used for primary parachute deployment.

EEPROM Size: Defines onboard flash/memory capacity.

Beep ON / OFF: Toggles continuity beeper audio.

End of Recording Altitude: Altitude threshold below which flight recording stops.

Record Temperature: Enables or disables onboard temperature recording.

Supersonic Delay: Ignores barometric pressure anomalies caused by shockwaves during the initial seconds of high-speed flight.

Liftoff Altitude: Altitude threshold to confirm launch has occurred.

Battery Type: Defines battery chemistry to configure low-voltage threshold alarms.

Altimeter Settings (Page 2)

Allows configuring measurement units (Metric/Imperial), continuity beep modes, and beep frequency tone.

Servo Configuration

Available exclusively when connected to AltiServo boards. Allows defining start, neutral, and deployed positions for each servo.
