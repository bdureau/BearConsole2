Firmware flashen

Zuerst müssen Sie die Firmware auswählen. Die Firmware hängt vom Höhenmessermodell ab, das Sie flashen möchten.

Entscheiden Sie dann, ob Sie direkt die Betriebsfirmware flashen oder zuerst eine Wiederherstellungsfirmware verwenden.

Wiederherstellungsfirmware: Verwenden Sie eine Wiederherstellungsfirmware, wenn die Konfiguration beschädigt ist und sich der Höhenmesser nicht mehr verbinden kann. Nach dem Laden einer Wiederherstellungsfirmware müssen Sie die Betriebsfirmware erneut flashen.
⚠ ACHTUNG
Das Flashen der falschen Firmware führt dazu, dass der Höhenmesser gar nicht oder nicht wie erwartet funktioniert.

Benötigte Hardware

  • Ein USB-TTL-Seriellkabel zum Anschluss an Ihr Telefon/Tablet.
  • Ein USB-OTG-Adapter (USB-C oder Micro-USB, je nach Android-Gerät).
  • Passende JST-Verbindungskabel.

Unterstützte Höhenmesser

Bitte sehen Sie sich die folgenden Bilder genau an, um Ihre Hardware zu bestimmen:

• AltiDuo (große Ausführung)

• AltiServo

• AltiMulti

• AltiMultiV2

• AltiMultiSTM32 oder AltiGPS

• AltiMultiESP32

• AltiMulti ESP32 accel

• AltiMulti ESP32 accel 345

• AltiMulti ESP32 accel 375

• TTGO BearAltimeter

Anleitung zum Flashen des Mikrocontrollers

Alternativ können Sie versuchen, die Firmware automatisch zu erkennen.

1. Höhenmesser mit ATmega328 (z. B. AltiDuo, AltiServo, AltiMulti, AltiMultiV2)

  • Schließen Sie das USB-TTL-Kabel an den Höhenmesser an.
  • Wählen Sie die richtige Firmware oder lassen Sie sie automatisch erkennen.
  • Drücken Sie kurz die Taste reset am Höhenmesser und tippen Sie dann auf [Firmware flashen].

2. Höhenmesser mit STM32 (z. B. AltiMultiSTM32, AltiGPS)

  • Schließen Sie das USB-TTL-Kabel an.
  • Wählen Sie die richtige Firmware oder lassen Sie sie automatisch erkennen.
  • Setzen Sie den Jumper BOOT0 nach rechts (Programmierposition):

  • Drücken Sie die Taste reset auf der Platine.
  • Tippen Sie auf [Firmware flashen].
  • Die Firmware sollte jetzt geladen werden. Setzen Sie danach den Jumper BOOT0 wieder nach links (Betriebsposition):

  • Drücken Sie die Taste reset, um den Höhenmesser im Normalmodus neu zu starten.

3. Höhenmesser mit ESP32 (z. B. AltiMultiESP32 und die AltiMultiESP32Accel-Varianten)

  • Schließen Sie das Kabel an.
  • Wählen Sie die richtige Firmware oder lassen Sie sie automatisch erkennen.
  • Drücken und halten Sie auf der Platine die Taste BOOT.
  • Drücken Sie die Taste RESET und lassen Sie sie los, während Sie die BOOT-Taste weiter gedrückt halten.
  • Lassen Sie die Taste BOOT los:

  • Tippen Sie auf [Firmware flashen].
  • Die Firmware sollte jetzt geladen werden (bei einem Fehler erneut versuchen). Drücken Sie danach die Taste reset.

4. TTGO BearAltimeter

  • Schließen Sie das USB-C-Kabel direkt an.
  • Wählen Sie die Firmware TTGO BearAltimeter.
  • Tippen Sie auf [Firmware flashen]. Drücken Sie danach die Taste reset.

5. TTGO Mini, Simple Altimeter & TS-ESP32-S3

  • Schließen Sie das USB-C-Kabel an.
  • Drücken und halten Sie die Taste BOOT auf der Platine.
  • Drücken Sie kurz die Taste RESET, während Sie die BOOT-Taste weiter gedrückt halten.
  • Lassen Sie die Taste BOOT los und wählen Sie das richtige Höhenmessermodell.
  • Tippen Sie auf [Firmware flashen]. Drücken Sie danach die Taste reset.
⚠ WICHTIGER HINWEIS
Trennen Sie das Kabel niemals während des Flashens. Andernfalls wird das Firmware-Abbild beschädigt und muss vollständig neu geflasht werden.
