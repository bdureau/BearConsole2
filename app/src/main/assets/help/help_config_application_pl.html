Ustawienia aplikacji Bear Console

Ustawienia aplikacji są podzielone na dwie karty: Ogólne i Telemetria.

1. Ustawienia ogólne

Język aplikacji: Pokazuje wybrany język (domyślnie automatycznie odpowiada językowi systemu Android).

Kolor wykresu: Ustawia kolor linii krzywych lotu (wysokość, przyspieszenie, prędkość).

Jednostki aplikacji: Przełącza między jednostkami metrycznymi (metry, m/s) i imperialnymi (stopy, ft/s).

Kolor tła wykresu: Ustawia kolor tła widoku wykresu. Zadbaj o wystarczający kontrast z kolorem linii!

Rozmiar czcionki: Dostosowuje rozmiar tekstu na wykresach i ekranach konsoli.

Prędkość transmisji: Ustawia prędkość komunikacji przy bezpośrednim połączeniu kablem USB OTG (musi odpowiadać prędkości portu szeregowego wysokościomierza, zwykle 38400).

Typ połączenia: Wybór między Bluetooth (krótki zasięg) a USB (kabel bezpośredni lub radiowe moduły LoRa/3DR dalekiego zasięgu).

Biblioteka graficzna: Pozwala przełączać silniki wyświetlania. Uwaga: na urządzeniach z Androidem 8.0 lub nowszym trzeba używać biblioteki MPAndroidChart, aby uniknąć awarii aplikacji.

Wiele spadochronów głównych / hamujących: Pozwala przypisać więcej niż jedno wyjście pirotechniczne do otwarcia spadochronu głównego lub hamującego.

⚠ OSTRZEŻENIE DOTYCZĄCE USB
Pełna obsługa USB: Włączaj tylko przy bezpośrednim połączeniu z płytką wysokościomierza kablem USB-TTL. Pozostaw wyłączone przy korzystaniu z bezprzewodowych modułów telemetrii dalekiego zasięgu (LoRa / 3DR), aby nie uszkodzić konfiguracji w EEPROM.

2. Ustawienia telemetrii

Zdarzenia dźwiękowe: Wybiera, które zdarzenia lotu są zapowiadane głosowo w czasie rzeczywistym (np. start, apogeum, otwarcie głównego, wysokość).

Głos syntezy mowy: Wybiera głos syntezy mowy (TTS) używany do komunikatów.

Test głosu: Dotknij [Testuj głos], aby sprawdzić głośność i wyrazistość syntezowanego głosu.

Zapisywanie zmian

Dotknij [Zapisz], aby zastosować i zachować nowe parametry. Możesz też wyjść bez zapisywania lub przywrócić ustawienia fabryczne za pomocą odpowiednich opcji menu.
