Hilfe zum Flugbildschirm

Der Bereich „Flüge“ ist auf zwei Bildschirme verteilt:

Kurvenansicht: Zeigt interaktive Flugkurven (Höhe, Beschleunigung, Geschwindigkeit). Auf diesem Bildschirm können Sie auswählen, welche Kurven angezeigt oder ausgeblendet werden.

Fluginfo: Zeigt eine vollständige Zusammenfassung der Flugtelemetrie (Gipfelpunkt, Höchstgeschwindigkeit, Brenndauer, Sinkgeschwindigkeiten). Sie können die aufgezeichneten Rohdaten auch in eine CSV-Datei exportieren.

Exporttipp: Die erzeugte CSV-Datei lässt sich in externer Software oder Tabellenkalkulationen für eine genaue Flug- und Leistungsanalyse auswerten.
