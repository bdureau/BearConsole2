Configuration d'un module eByte LoRa E220

De manière à pouvoir effectuer de la télémétrie longue distance, vous devez remplacer votre module Bluetooth par un module de télémétrie longue portée comme le LoRa E220.

Modules testés et validés

  • E220-400T30D
  • E220-400T30S
  • E220-900T30D
  • E220-900T30S
  • E220-400T22D
  • E220-900T22S

Alimentation électrique : À noter que la batterie de votre appareil Android doit être suffisamment puissante pour alimenter le module LoRa. Envisagez l'utilisation d'une batterie externe si vous avez un module puissant (comme les modèles de 30dBm / 1W).

Matériel requis

  • Un câble adaptateur USB vers série TTL.
  • Un adaptateur USB (USB-C ou Micro-USB en fonction de votre appareil Android).
  • Un adaptateur JST et des cordons de liaison JST.
⚠ CRITIQUE : CAVALIERS DE MODE (M0 / M1)
De manière à mettre le module en mode configuration, il faut impérativement mettre les 2 cavaliers (M0 et M1). Avant d'utiliser le module en vol, assurez-vous d'enlever les 2 cavaliers pour sortir du mode configuration et rétablir la transmission normale.

Harmonisation de la vitesse (Baud Rate)

Vous devez configurer votre module de manière à ce qu'il puisse fonctionner avec votre altimètre. À noter que ces modules sont en général préconfigurés à 57600 bauds. Cependant, votre altimètre par défaut sera configuré à 38400 bauds : vous devez donc vous assurer de configurer la vitesse de communication opérationnelle adéquate.

⚠ ATTENTION
Assurez-vous de ne pas débrancher le module lorsque vous effectuez les opérations suivantes.

Procédure de configuration

  1. Préparation matérielle : Mettez les 2 cavaliers sur le module. Branchez le module sur votre appareil Android en utilisant un câble USB-TTL et un adaptateur USB OTG.
  2. Charger la configuration : Cliquez sur [Charger cfg]. L'application effectuera des tentatives de connexion au module à 9600 bauds, puis affichera les paramètres actuels pour que vous puissiez les modifier.
  3. Sauvegarder la configuration : Changez les paramètres souhaités. Assurez-vous d'avoir choisi la vitesse qui fonctionnera avec votre carte (par défaut 38400 bauds). Assurez-vous que les canaux de fréquence sont strictement identiques pour l'émetteur et le récepteur. Si vous utilisez une clé de chiffrement, assurez-vous qu'elle soit la même des deux côtés. Cliquez sur [Sauver cfg]. En cas d'erreur lors de la sauvegarde, celle-ci sera annulée.
  4. Sortie du mode configuration : Débranchez le module et enlevez les 2 cavaliers avant toute installation sur la fusée ou au sol.
Modules par paire : À noter que les modules LoRa sont vendus par paire, il sera donc nécessaire de répéter la même opération pour l'émetteur et le récepteur.
Remarque : Les modules de télémétrie LoRa ne fonctionnent pas actuellement avec les cartes ESP32.
