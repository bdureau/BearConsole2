3DR Module Configuration

In order to do long range telemetry you will need to replace your Bluetooth module with a 3DR telemetry module.

Power Note: Note that your Android device battery must be strong enough to power the 3DR module. Consider using an external battery if you have a powerful module.

Required Hardware

  • A USB-to-TTL serial adapter cable.
  • A USB adapter (USB-C or Micro-USB depending on your Android device).
  • A JST adapter and matching JST cables.

Baud Rate Compatibility

You will need to configure the module so that it works with your altimeter board. Note that these modules usually come preset to work at 57600 baud. However, your altimeter board by default will work at 38400 baud, so you need to make sure that you are connecting at the correct speed.

⚠ CAUTION
Make sure that you do not unplug or disconnect the module while performing configuration steps to prevent memory corruption.

Configuration Steps

  1. Retrieving Configuration: Plug the module into your Android device using an OTG cable or USB adapter. Tap [Retrieve cfg]. The app will test various baud rates until it connects, then load the module configuration.
  2. Saving Configuration: Change the parameters you want to modify. Ensure you select a baud rate compatible with your board (38400 baud) and tap [Save cfg]. If any error occurs while saving, the process will abort safely.
Paired Modules: 3DR modules come in pairs, so you must repeat these exact steps for both the transmitter and receiver modules.
